# 🧩 Team Management Platform

**Tech Stack:** Spring Boot • Angular • MySQL

## 📋 Overview
A collaborative task and workflow platform that allows teams to manage projects with real-time dashboards and notifications.

## 🚀 Features
- Real-time task updates and Kanban-style board
- Automated alerts for deadlines
- Role-based access control
- Optimized database queries and caching for fast performance

## ⚙️ Setup
1. Create DB using `database/schema.sql`
2. Start backend:
   ```
   cd backend
   mvn spring-boot:run
   ```
3. Start frontend:
   ```
   cd frontend
   ng serve
   ```
4. Access app at `http://localhost:4200`
